# NayaBill

Invoice + WhatsApp payment requests for freelancers (JazzCash, Easypaisa, bank, Payoneer).

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

See [EARNING.md](./EARNING.md). Configure checkout via `.env.example`.
